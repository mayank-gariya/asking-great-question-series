# AI Workforce Displacement Analysis (2020-2026)

## 📊 Project Overview

This project provides a comprehensive analysis of artificial intelligence's impact on the global workforce from 2020 to 2026. It combines data analysis, visualization, and reporting to understand trends in job displacement and AI adoption across industries and regions.

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook
- Power BI Desktop (for dashboard viewing)
- Microsoft Word or compatible software (for report)

### Installation

```bash
# Install required Python packages
pip install pandas numpy matplotlib seaborn jupyter

# Launch Jupyter Notebook
jupyter notebook Day-2.ipynb
```

### Usage

1. **Explore the Notebook**: Run `Day-2.ipynb` to see the full analysis pipeline
2. **View the Dashboard**: Open `dashboard.pbix` in Power BI Desktop
3. **Read the Report**: Review `2020 to 2026 AI report.docx` for detailed insights
4. **Analyze the Data**: Use `ai_workforce_displacement_global_2020_2026.csv` for custom analysis
